# Aim Duel Trainer

FPS-тренажёр аима с двумя режимами:

- **Тренировка с ботом** (основной рабочий режим)
- **Сетевой 1v1** (подготовлен теми же механиками)

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Что улучшено

- Исправлено движение влево/вправо и вперёд/назад в обоих режимах
- Хитбоксы головы и тела синхронизированы с видимой моделью
- Добавлены визуальные эффекты получения урона и смерти
- Добавлена полоска HP над ботом
- Есть полоска HP игрока, патроны, перезарядка, счёт и таймер

## Как играть

1. Введите ник (необязательно)
2. Выберите режим:
   - **Тренировка с ботом** — бот двигается, стреляет и респавнится
   - **Сетевой 1v1** — использует те же правки по управлению/стрельбе/хитбоксам
3. Кликните в игру для захвата курсора

## Управление

- `W A S D` — движение
- Мышь — прицеливание
- `ЛКМ` (можно зажимать) — стрельба
- `R` — перезарядка
- `Esc` — отпустить курсор
