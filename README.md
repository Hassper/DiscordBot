# Aim Duel Trainer

FPS-тренажёр аима с двумя режимами:

- **Тренировка с ботом** (основной режим)
- **Сетевой 1v1** (те же механики)

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Новые улучшения

- Здоровье увеличено в 5 раз: теперь у игрока и целей по `500 HP`
- Исправлены и синхронизированы хитбоксы головы/тела в PvE и PvP
- Добавлен прыжок игрока (`Space`) и прыжки бота
- Добавлена настройка чувствительности мыши в главном меню
- Добавлено главное меню с выбором режима и быстрым возвратом кнопкой `Меню`
- Патроны вынесены в правый нижний угол с отдельным оформлением
- После убийства боезапас восполняется
- Добавлен FPS-счётчик и переключение герцовки рендера (`60/120/∞`)
- Добавлен позиционный звук появления бота, чтобы понимать направление появления

## Управление

- `W A S D` — движение
- `Space` — прыжок
- Мышь — прицеливание
- `ЛКМ` (можно зажимать) — стрельба
- `R` — перезарядка
- `Esc` — отпустить курсор
