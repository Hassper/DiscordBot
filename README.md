# Aim Duel Trainer

FPS-тренажёр аима с двумя режимами:

- **Тренировка с ботом** (мгновенный соло-режим)
- **Сетевой 1v1** (дуэль против другого игрока)

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Что улучшено

- Плавное и предсказуемое движение во все стороны (включая диагонали)
- Более точные хитбоксы (тело + голова), headshot регистрируется отдельно
- Более отзывчивая стрельба: можно зажимать ЛКМ, есть ограничение скорострельности
- HUD с полоской HP, патронами/перезарядкой, счётом и таймером матча
- Звуки выстрела, попадания и перезарядки

## Как играть

1. Введите ник (необязательно)
2. Выберите режим:
   - **Тренировка с ботом** — бот двигается, стреляет и респавнится
   - **Сетевой 1v1** — откройте вторую вкладку или подключите другое устройство
3. Кликните в игру для захвата курсора

## Управление

- `W A S D` — движение
- Мышь — прицеливание
- `ЛКМ` (можно зажимать) — стрельба
- `R` — перезарядка
- `Esc` — отпустить курсор

## Сетевая игра с другом

- Запустите сервер на хосте: `npm start`
- Откройте порт `3000`
- Друг подключается по адресу `http://<IP_хоста>:3000`
