# Aim Duel Trainer

Обновлённый FPS-тренажёр с PvE-уровнями, кастомизацией и бенчмарком.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Что исправлено и добавлено

- Оружие в руках уменьшено, сдвинуто вправо и переделано под более узнаваемую форму
- Бенчмарк упрощён: меньше сфер, ниже скорость, увеличен размер, попадания стабильнее
- Кастомный курсор убран
- В магазине есть визуальные превью товаров (модель врага, оружие, тип прицела)
- Сложность PvE-уровней снижена
- За каждое убийство в PvE теперь даётся 1 звезда
- Добавлен выбор сложности бота в PvE: easy / normal / hard
- Ландшафт сделан более мягким по цветам и добавлена текстура грунта
- В PvE добавлены разные карты с препятствиями и коллизией
- Добавлено отображение текущей скорости перемещения

## Управление

- `W A S D` — движение
- `Space` — прыжок
- `ЛКМ` (зажим) — стрельба
- `R` — перезарядка
- `M` — открыть/закрыть меню
