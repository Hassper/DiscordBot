# Aim Duel Trainer

FPS-тренажёр аима с двумя режимами:

- **Тренировка с ботом** (мгновенно, можно играть одному)
- **Сетевой 1v1** (против другого игрока)

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Как играть

1. Введите ник (необязательно).
2. Выберите режим:
   - **Тренировка с ботом** — бот двигается по арене, стреляет и респавнится.
   - **Сетевой 1v1** — откройте вторую вкладку или зайдите с другого устройства.
3. Нажмите в экран для захвата курсора (pointer lock).

## Управление

- `W A S D` — перемещение
- Мышь — прицеливание
- ЛКМ — выстрел
- `Esc` — отпустить курсор

## Сетевая игра с другом

- Запустите сервер на хосте: `npm start`
- Откройте порт `3000`
- Друг подключается по адресу `http://<IP_хоста>:3000`
