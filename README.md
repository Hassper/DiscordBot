# Aim Duel Trainer

Обновлённый FPS-тренажёр с PvE-уровнями, кастомизацией и бенчмарком.

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000`.

## Главное

- Постоянный игровой захват с оверлеем возврата фокуса (кнопка меню: `M`)
- 10 PvE-уровней с ростом сложности, таймером, звёздами и прогрессом
- Магазин косметики за звёзды и инвентарь (скины противника/оружия, виды прицела)
- Режим Benchmark (1 минута): стрельба по летающим сферам без движения
- Таблица лидеров Benchmark (топ-10, хранится локально)
- HP увеличено до `500` в обоих режимах
- Прыжки игрока и бота
- Патроны оформлены справа снизу, есть пополнение после убийства
- Отображение оружия в руках с визуальной отдачей
- FPS-счётчик и ограничение герцовки рендера (60/120/∞)
- Позиционный звук появления бота

## Управление

- `W A S D` — движение
- `Space` — прыжок
- `ЛКМ` (зажим) — стрельба
- `R` — перезарядка
- `M` — открыть/закрыть меню
