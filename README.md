# Aim Duel Trainer (1v1)

Простой сетевой FPS-тренажёр аима в духе Aim Labs/Kovaak:

- Вид от первого лица
- Дуэль между двумя игроками по сети
- Простая арена и базовое управление
- Основной фокус — наводка и стрельба по движущейся цели

## Запуск

```bash
npm install
npm start
```

Откройте `http://localhost:3000` в двух вкладках (или на двух устройствах в одной сети) и начните дуэль.

## Управление

- `W A S D` — перемещение
- Мышь — прицеливание
- ЛКМ — выстрел
- `Esc` — отпустить курсор
